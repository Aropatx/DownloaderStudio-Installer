# Downloader Studio

Aplikacja Windows do pobierania filmów i muzyki z YouTube.

## Pobierz

**[⬇ Pobierz najnowszy instalator](https://github.com/Aropatx/DownloaderStudio-Installer/releases/latest/download/DownloaderStudio-Setup.exe)**

Windows 10 (1809+) lub Windows 11, 64-bit. Instalacja dla bieżącego użytkownika, bez uprawnień administratora. Instalator zawiera wszystko, czego aplikacja potrzebuje.

## Aktualizacje

Instalujesz tylko raz. Gdy pojawi się nowa wersja, aplikacja pokaże u góry okna pasek z przyciskiem **Zaktualizuj**. Jedno kliknięcie pobiera aktualizację, instaluje ją i uruchamia aplikację ponownie. Twoja biblioteka, ustawienia i pobrane pliki zostają.

## Co potrafi

- Wideo (MP4, MKV, WebM, do 4K) i dźwięk (MP3, M4A, Opus, FLAC, WAV)
- Kolejka pobrań: wiele linków naraz, kilka pobrań jednocześnie
- Playlisty: wybierasz, które filmy pobrać
- Wycinanie fragmentu, okładka i tagi, napisy
- Powiadomienia Windows po zakończeniu pobierania
- Wygląd Windows 11: efekt Mica, motyw jasny, ciemny, granatowy lub OLED
- Polski i angielski

# Downloader Studio (English)

A Windows app for downloading YouTube videos and music.

**[⬇ Download the latest installer](https://github.com/Aropatx/DownloaderStudio-Installer/releases/latest/download/DownloaderStudio-Setup.exe)**. Requires 64-bit Windows 10 (1809+) or Windows 11. No admin rights needed.

Install it once. When a new version is out, the app shows an **Update** button. One click downloads it, installs it and restarts the app. Your library, settings and downloads stay as they are.
